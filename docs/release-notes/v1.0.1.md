## Reminder Desk 1.0.1

Correção da inicialização com o Windows e novo atalho na Área de Trabalho.

### Corrigido

- **Iniciar com o Windows na versão portátil**: o aplicativo registrava a pasta temporária onde o `.exe` portátil se descompacta, que é apagada ao sair, então nada abria no logon. Agora é registrado o arquivo original que você abriu.

### Novo

- **Criar atalho**: em Configurações, o botão "Criar atalho" cria `Reminder Desk.lnk` na Área de Trabalho, apontando para o executável em uso.

### Como atualizar

Substitua o arquivo antigo pelo novo e abra o aplicativo **uma vez**: a entrada de inicialização do Windows é corrigida automaticamente. Seus lembretes, categorias e configurações são mantidos.

Na versão portátil, se você mover o `.exe` de lugar, abra-o uma vez no novo local para atualizar a inicialização.
